So hey guys!  THis is a repository for holding the avatar and world portal lists that are used in my Vrchat worlds.  I used to have them on pastebin but having them here on github means that others (namely, you), can add to those avatar lists and world lists whenever you make or find any new avatars or worlds.  Feel free to update any and all the lists whenever you have stuff to add, or remove when you find something that's broken like a deleted avatar.

The current Avatars list is under "FatFurAvatars" and the ones that start with "HeavyAvtrs..." are the updated ones.  The old outdated ones start with "HeavyRAvatars..." and are left there because at least 1 other world is using them and deleting them would break things in that world.  So leave those alone and instead only update the other ones.
